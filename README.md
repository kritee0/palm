# 💬 Real-Time Chat App

A full-stack real-time chat application built using **Node.js, Express, MongoDB, Socket.IO, and React**.

---

# 🚀 Features

- 🔐 User Authentication (Register/Login with JWT)
- 💬 Real-time chat using Socket.IO
- 💾 Chat history stored in MongoDB
-
- 📊 Total users & messages count APIs

---

# 🛠️ Tech Stack

## Backend
- Node.js
- Express.js
- MongoDB
- Socket.IO
- JWT Authentication

## Frontend
- React.js
- Tailwind CSS
- Socket.IO Client
